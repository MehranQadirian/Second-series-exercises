:star: JK Flip-Flop

| J | K | CLK (Clock) | خروجی Q | توضیحات |
|:---:|:---:|:---:|:---:|:---:|
| 0 | 0 |       1      | Q       | وضعیت قبلی حفظ می‌شود. |
| 0 | 1 |       1      | 0       | خروجی Reset می‌شود. |
| 1 | 0 |       1      | 1       | خروجی Set می‌شود. |
| 1 | 1 |      1       | Q'      | خروجی Toggle می‌شود. |
