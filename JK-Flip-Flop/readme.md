:star: JK Flip-Flop

| ورودی‌ها | J | K | CLK (Clock) | خروجی Q | توضیحات |
|----------|---|---|-------------|---------|---------|
| ↑        | 0 | 0 |             | Q       | وضعیت قبلی حفظ می‌شود. |
| ↑        | 0 | 1 |             | 0       | خروجی Reset می‌شود. |
| ↑        | 1 | 0 |             | 1       | خروجی Set می‌شود. |
| ↑        | 1 | 1 |             | Q'      | خروجی Toggle می‌شود. |
